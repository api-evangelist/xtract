# Xtract

Xtract was a social-intelligence analytics company that refined social interaction, behaviour, and demographic data from telecom operators into detailed subscriber profiles through its Social Links platform — churn prevention, product marketing, customer acquisition, and demographics prediction. Surfaced as a Creandum portfolio company (listed as exited); its websites (xtract.fi, xtract.com) are offline and no public API surface exists.
